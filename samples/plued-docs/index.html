PLUed Help

Online help for PLUed, an app I built that teaches grocery cashiers the PLU codes for fresh produce. It is written in DITA XML and published with the DITA Open Toolkit. One source produces two help sites: one for cashiers and shoppers, and one that adds the topics for store managers and trainers.

  • Online help

    User help

    For cashiers and shoppers: look up a code, scan a sticker, study, practice and set up the app.

  • Online help

    Admin help

    Everything in the user help, plus building and sharing a store's codes and managing store codes.

  • Write-up

    How I built it

    The brief, the DITA structure with real excerpts, how it is published, and how it was checked.
