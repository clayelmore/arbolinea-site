    Task

    Choose the codes you study

    Every code has a star. Turn a star off for a code your store does not use, and the code leaves your flashcards, games and mastery count.

    Before you begin

    Open the concept card of the item.

    About this task

    Every code starts starred. A retired or Non-US code is left out of practice. If your store still uses one, you can star it back in.

    Procedure

    1. In the Codes section, find the row of the code.
    2. Tap the star on that row.
      A filled star turns to an outline, and the code leaves your study set. An outlined star fills in, and the code comes back.
    3. Optional: To study a code with a Retired or Non-US chip, tap the star on its row.
      The app asks Your store still uses code?
    4. Optional: Tap Add to my training.

      To keep the code out of practice, tap Cancel instead.

      The chip changes to Still in use. The code is back in your flashcards, games and mastery count.

    What to do next

    The Starred chip in Flashcards studies only the codes you keep starred.
