    Task

    Look up a PLU code

    Search the Library by name, code or other name to find an item and open its concept card.

    Procedure

    1. At the bottom of the screen, tap Library.
    2. Tap the search box, Name, PLU or alias.
    3. Type a name, a code, an organic code or another name for the item.

      For example, type banana, 4011 or 94011. Words can be in any order. When the app is in Spanish, search by the Spanish name.

      If you typed a full code that belongs to one item, its concept card opens by itself. Otherwise the grid shows the matching items.
    4. Tap the item's card in the grid.

      If only one item matches, you can tap the search key on the keyboard instead.

      The concept card opens with the item's codes.

    Results

    Note:
    For the organic version of any code, add a 9 in front of it. For example, 4011 becomes 94011.

    If nothing matches, the Library says so. A cashier can then tap Add "search" as a Store Code to add the item as a store code.
