    Import your store's pack

    A store pack holds a store's own codes, its practice lists and the pictures for each item. Import the pack your trainer shared to study your store's codes.

    Before you begin

    A trainer or manager shared a pack with you as a QR code, a link or a .plupack file. A QR code or link needs a connection the first time you import it.

    About this task

    If you tap a pack link on a phone that has the app, the app opens Import Store Pack and starts the import by itself. Continue with step 5.

    Procedure

    1. At the bottom of the screen, tap Library.
    2. Tap Import Pack.

      Before you have any pack, Home also has an Add a Store Pack row that opens the same screen. In the shopper view, tap Add your store on Home.

      The Import Store Pack screen opens.
    3. Decide how you received the pack.
      IfThen
      A QR code Tap Scan QR and point the camera at the QR code. The import starts when the code is read. Continue with step 5.
      A link or code in a message Paste it in the STORE PACK LINK OR CODE box. Continue with step 4.
      A .plupack file Tap Open .plupack File and choose the file. The import starts when you choose it. Continue with step 5.
    4. Tap Import.
    5. If Codes already in your store opens, tap Keep both or Replace mine.

      This happens when the pack uses a code you already have from another pack or added yourself.

    6. On Store Pack imported, tap OK.
      The message lists how many codes and practice lists came in.

    Results

    Your store's items appear on Home under your store's name, and carry a STORE badge in the Library. When the trainer updates the pack, Update available shows beside it on Import Store Pack.

    Note:
    Looking at your store's pack is free. Practicing it needs the full app or a store code.
