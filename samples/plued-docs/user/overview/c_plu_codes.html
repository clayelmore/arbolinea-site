    Concept

    How PLU codes work

    A PLU code is a 4-digit number that identifies a fresh produce item at the register. The International Federation for Produce Standards (IFPS) assigns the standard codes.

    Standard codes

    Standard codes run from 3000 to 4999. The same code means the same item in every store that uses the standard list. For example, 4011 is bananas.

    Note:
    For the organic version of any code, add a 9 in front of it. For example, 4011 becomes 94011.

    One item, several codes

    An item can have a separate code for each of these:

    Size
    Small, medium and large fruit of one variety can each have their own code. For navel oranges, 4012 is large, 3107 is medium and 4013 is small.
    Region
    Some produce has one code in the East and Central United States and another in the West.
    Growing method or form
    Some items have separate codes for how they are grown or how they are sold, such as loose or in a bunch.

    Each of these codes is its own answer. Entering the code for a different size counts as a miss.

    Store codes

    A store can also use its own codes for items that have no standard code, or for items it prices its own way. In the Library, PLUed calls these store codes. A store shares them with its cashiers in a store pack.

    The code a store gives its cashiers with a Store Plan is a different thing. It unlocks the app and is not a produce code.

    Retired and restricted codes

    IFPS retires a code now and then, and restricts a few from use in the United States and Canada. The app shows such a code with a Retired or Non-US label and leaves it out of practice. If your store still uses one, star it to add it back to your training.
