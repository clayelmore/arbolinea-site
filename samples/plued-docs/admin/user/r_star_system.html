    Stars in Quick Play

    Each Quick Play session starts with 5 stars. This table lists how each answer changes your stars.

    Table 1. Star changes per answer
    What you did Stars Item goes to Break Time
    Typed the right code within 3 seconds, no hint +2 No
    Typed the right code after 3 seconds, no hint +1 No
    Tapped the item's tag (What Kind?), then typed the right code 0 No
    Tapped Lookup -1 Yes
    Retyped the code that Lookup showed 0 Already added
    Typed a wrong code, including the code for another size of the same item, or for another region unless the two codes are regional twins -1 Yes
    Let the item reach the end of the belt -1 Yes

    Limits

    • Stars never go below 0. At 0, Break Time starts.
    • After Break Time, you go back to the belt with 3 stars.
    • Practice mode uses no stars.
