    Build a store pack

    Type your store's codes into the Store Pack Builder one row at a time. Codes that PLUed already teaches fill in their own row.

    Before you begin

    • A computer or tablet with a web browser and an internet connection.
    • Your store's name and your list of produce codes.

    Procedure

    1. In a web browser, open plued.app/pack.
      The Store Pack Builder opens. It runs in the browser and needs no account.
    2. Under Store name, type the name your cashiers know.

      Use up to 30 characters, with no single word over 16 letters.

    3. Tap Next →.
      Step 2, Add your codes, opens with one empty row.
    4. In the Code box, type a code of 3 to 5 digits.

      If PLUed teaches the code, the row fills in the name, size, category, section and picture, and shows IN PLUed. The builder fills only empty fields. Anything you typed first stays.

    5. For one of your store's own codes, type the item name in the Name box.

      Use up to 40 characters. A code can appear in the pack once. A second row with the same code shows Duplicate code.

      The builder picks the closest picture from the PLUed catalog.
    6. Choose Fruit, Veg or Other, and a Size if the code is for one size.
    7. Open the Section menu and pick the aisle the item belongs to.

      To make your own section, pick + New section…, type a name of up to 32 characters, and tap Add. To rename a section for every row in it, pick Rename section….

    8. Check the picture on the row.

      To change it, tap the picture or Change. The Use a PLUed image box opens with Suggestions and a search box. Tap the picture closest to your item. A row with no picture shows CHECK GRAPHIC and a Use PLUed image button.

    9. Optional: If no picture fits one of your store's own codes, tap Request a graphic.

      Describe what the item looks like in up to 200 characters, for example "yellow cherry with a red blush, sold loose", and tap Request. Keep the closest picture on the row until the new one is ready. The request is sent when you share the pack.

      Request a graphic shows only for a code that PLUed does not teach, once the row has a code and a name.

      The row shows GRAPHIC REQUESTED.
    10. Tap Add code and repeat steps 4 to 9 for each item.
    11. Optional: On step 3, Practice lists, tap Add practice list.

      Type a List name, tap Items, tick the items for the list, and tap Done. Your own codes are listed first.

    Results

    Step 4, Share with your team, reads Ready to share. If it reads Still to do before you can share, tap a line in its list to go to the field that needs a change.
