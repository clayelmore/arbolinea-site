    Store pack spreadsheet columns

    The Store Pack Builder reads a .csv file or the first sheet of an .xlsx workbook. The first row names the columns, and each row after it is one code.

    Table 1. Columns
    ColumnRequiredWhat goes in itOther headers read as this column
    codeYesThe standard PLU or the store's own code: 3 to 5 digits, numbers only.PLU, PLU Number, SKU, Item, Item Code
    nameYesThe item name cashiers see, up to 40 characters.PLU Description, Item Name, Item Description
    categoryYesA value that starts with fruit or veg, such as vegetable. Any other value is filed as Other.Dept, Department, Dept No
    sizeNoA size word from the size table below.None
    descriptionNoWhat the item looks like, such as "large green apple, waxy skin". The builder uses it with the name to choose a picture. It is not stored in the pack.Desc, Appearance, Looks

    How headers are read

    • Headers are read in English. Capital letters, spaces, underscores and hyphens do not matter, so Item Code and item_code are the same.
    • A file with a description column and no name column uses the description column as the name. Many register exports name the item this way.
    • Columns the builder does not know are ignored.
    Table 2. Size words
    Word in the fileSize in the pack
    XS, Extra Small, XSmallXS
    S, Sm, SmallS
    M, Med, MediumM
    L, Lg, LargeL
    XL, Extra Large, XLargeXL
    Blank, Each, EA, All, All Sizes, N/A, NA, NoneNo size

    What happens to each row

    A standard PLU
    The row takes the PLUed picture and section for that code.
    A store's own code
    The builder picks the closest picture from the name and the description. Check its picture and its section in the builder.
    A blank row
    Skipped without a message.
    A code that is not 3 to 5 digits
    Skipped. The result box names the row, for example Row 9: code 123456 is not 3-5 digits.
    Another category
    Imported as Other. The result box says so, for example Row 7: category [Deli] mapped to other.
    An unknown size word
    Imported with no size. A message on the row asks you to pick a size or leave it blank for all sizes.
    A name that is too long
    Imported as written. Step 4 lists it under Still to do before you can share until you shorten it.
    The same code twice in the file
    The later row updates the earlier one.
    A code already in the builder
    The row in the builder is updated with the file's name, category and size. No second row is added.
    A missing required column
    Nothing is imported. The message names the missing column.

    Row numbers in the messages count the header row as row 1 and skip blank rows, so after a blank row they run one lower than the spreadsheet's own row numbers. In an Excel workbook only the first sheet is read. Excel drops a zero at the start of a number, so format the code column as Text before you type or paste codes that start with 0.

    Example

    A short file with two standard PLUs and one store code:

    code,name,category,size,description
4011,Bananas,fruit,Each,classic yellow bananas
4225,Hass Avocado,fruit,Large,large dark pebbly avocado
830,Cut Watermelon Bowl,Deli,,red seedless watermelon cut in cubes

    The first two rows come in marked IN PLUed. The third is a store code with a category the builder does not know, so it comes in as Other, with a picture chosen from its name and description. Check its picture and its section.
