    Import a spreadsheet into a store pack

    Bring a long list of codes into the Store Pack Builder from a CSV file or an Excel workbook instead of typing each row. Every row that comes in gets a picture to check.

    Before you begin

    • Your produce list as a .csv or .xlsx file. Most register and back-office exports work as they are.
    • The first row of the file names the columns. The file needs a code column, a name column and a category column.

    Procedure

    1. In a web browser, open plued.app/pack.
      The Store Pack Builder opens. It runs in the browser and needs no account.
    2. Under Store name, type your store's name.
    3. Tap Next → to open step 2, Add your codes.
    4. Tap Import CSV / XLSX and choose your file.

      The same row of buttons has template.csv and template.xlsx, empty files with the right columns.

      The rows of your file appear in the table. A message at the bottom of the screen says for how many codes the builder matched a picture.

    5. Read the result box under the buttons.

      It says how many rows were imported and how many were skipped, with one line for each row that needs your attention. For example, Row 9: code 123456 is not 3-5 digits. names a row that was left out.

    6. Check the picture on each of your store's own codes.

      Rows marked IN PLUed already have their own picture and section. For other rows the builder chose the closest picture from the name and the description. Tap a picture to pick a better one. A row marked CHECK GRAPHIC has no picture yet.

    7. Open the Section menu on each of your store's own codes and pick its aisle.
    8. Decide whether to correct the file and import it again.
      IfThen
      You corrected rows in the file Repeat step 4. A code that is already in the table is updated in place, so no row is added twice.
      The table is right The task is complete.

    Results

    Every usable row of the file is in the table. When nothing is left to check, the line under Store codes ends with Everything has a graphic and a section. Ready to share.
