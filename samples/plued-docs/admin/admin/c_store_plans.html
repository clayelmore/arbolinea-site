    Concept

    Store Plans and store codes

    A Store Plan gives a store one store code and a number of seats. A cashier types the store code once, and PLUed is unlocked on that phone with nothing to pay.

    A store code is not a store pack

    The store code unlocks the app. The store pack adds your store's own codes. They are two separate things, each with its own QR code: the pack QR comes from the Store Pack Builder, and the store code poster comes from your store page. A store on a Store Plan posts both.

    How a cashier uses the store code

    The cashier taps I have a store code on the setup page at first launch. Later, the same entry is Did your store give you a code?, under any locked level or under Settings > Market access > Unlock everything. The cashier types the code, or taps Scan the poster and points the camera at the poster's QR code. On an iPhone or iPad, a second sheet from Apple opens, and the cashier enters the same store code there.

    When the phone is unlocked, Settings shows Licensed to with your store's name. The store code needs version 1.2 or later of the app.

    Seats

    • A seat is used the first time a phone unlocks with the store code. Typing the code again on the same phone uses no extra seat.
    • A phone that unlocks keeps its unlock. It stays unlocked if the plan is not renewed or if more seats are added.
    • Your store page shows how many seats are in use.
    • Each time the plan renews, the seat count starts again from zero. Phones unlocked in the year before stay unlocked and no longer count.

    When every seat is in use

    The next cashier who enters the store code sees All of your store's seats are in use. Ask your manager to add more. Under the message, Tell your manager opens the phone's share sheet with a short note the cashier can send you. Add seats from your store page. The store code stays the same.

    PLUed also emails your store's address when most of your seats are in use, and when a cashier could not join because no seat was left.
